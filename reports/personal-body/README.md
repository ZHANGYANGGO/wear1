## 验收操作

1. 用两位照片角色分别换装、命名并保存搭配。按 A → B → A 切回，再刷新。检查角色 ID、头部像素、穿着单品和可加载的搭配名称。从新标签页打开试穿台也能恢复已选照片角色。
2. 在同一个人身上分别确认合身版和直身版。两次都逐件试穿通用衣橱的 11 件已适配单品，覆盖上衣、下装、鞋、裙装和外套。检查细高跟的待适配状态。裙装盖住上下装，卸下裙装恢复原单品，外套独立叠穿和移除。
3. 将完整披肩发分别搭配浅色圆领、深色衬衫领和双层外套。对前发与不透明衣料的交叉区域逐像素比较，屏幕合成应保留发束颜色。另一位眼镜长发人物的原照截断了发尾，对后发与衬衫、外套的交叉区域检查衣料颜色。前后关系按照片中可见发束和肩部遮挡估计。
4. 换用第二套模板前后检查全部 478 个点的坐标变换。刷新后重新打开叠画，比较整个标记画布的像素。两边使用相同的原始头层。
5. 重新打开七个旧三层内置人物，并从短发女士的专属衣橱试穿专属衬衫。回读第二部分留下的旧卡通头层并进入试穿。另一标签页更新头层后，旧的身体预览无法覆盖新头层。

## 复跑

从 `wear-二维` 目录运行。浏览器脚本使用 Python 的 Playwright、Pillow 和 NumPy，还需要工作台的照片分析及卡通环境。首次复跑缺少样例时，验证脚本会下载摄影原图到 `.runtime`，并在独立的浏览器上下文中创建测试人物。

```powershell
node --test
node scripts/serve.mjs 4375
```

服务运行后，在另一个终端执行以下命令，浏览器路径可换成自己的 Chrome 或 Edge。

```powershell
python scripts/verify-personal-body.py --url http://127.0.0.1:4375 --browser "C:/Program Files/Google/Chrome/Application/chrome.exe"
```

完整披肩发和眼镜长发分别使用 Pexels 编号 774909、1239291 的照片，短发使用公开人脸示例集中的照片。[披肩发原图](https://images.pexels.com/photos/774909/pexels-photo-774909.jpeg) · [眼镜长发原图](https://images.pexels.com/photos/1239291/pexels-photo-1239291.jpeg) · [短发原图](https://github.com/ageitgey/face_recognition/blob/master/examples/obama.jpg)
