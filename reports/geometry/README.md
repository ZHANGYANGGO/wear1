# WearMate 模块三验收

开发基线为 `wear-mc-2` 的 `3dbcdfa`。创建页的「双视角拟合」「实测围度」「外观增强」共用本地几何模型。快速人台沿用原参数。在预览下方勾选「显示身高及围度量线」可以查看量体位置。

## 导出后复测

软尺在原始 `Body` 三角网格上，从脚底起分别在 1.212、1.06、0.83 m 处取胸、腰、臀的躯干闭环。每个测量点保存在三角形边上的相对位置。变形之后重新计算这些点的三维坐标，沿闭环累加线段长度，以厘米输出。手臂属于独立的截面，衣物属于独立网格。身高取足底与头顶的垂直距离。小腹另取 0.96 m 高度，用来核对腹背形态。

以下为同一组 170 cm、65 kg 的固定输入，两版均通过浏览器导出 GLB 后读取顶点。新版另外通过三维查看器重新载入下载文件。

## BodyM 轮廓预测

输入为正侧面轮廓、身高和体重。训练期间以人物为单位等权，用 train 中 1,608 人拟合，并在另外 410 人上选择岭回归系数。随后用 train 全部 6,134 对观测重新拟合并冻结权重。评估按照片生成最终网格，再与独立量体标签比较。预览、三个对照方法和 GLB 复测共用同一把网格尺。

旧版需要从关键点生成截面，BodyM 发布的遮罩没有关键点。本表通过模板比例定位截面，从同一份轮廓提取四个部位的宽度、厚度和置信度，再交给旧版拟合器。旧版栏表示这种适配后的成绩。快速人台只用身高、体重。

每格依次为按照片平均绝对误差、90% 分位绝对误差、按人等权平均绝对误差，单位 cm。

| 测试集 | 方法 | 胸围 | 腰围 | 臀围 |
|---|---|---:|---:|---:|
| testA | 快速人台 | 4.48 / 9.09 / 4.43 | 9.35 / 16.04 / 9.59 | 5.41 / 11.52 / 5.40 |
| testA | 旧照片拟合 | 3.48 / 7.30 / 3.54 | 5.62 / 10.17 / 5.65 | 4.56 / 9.03 / 4.50 |
| testA | 新照片拟合 | 2.51 / 5.22 / 2.45 | 2.76 / 5.97 / 2.76 | 1.52 / 2.97 / 1.51 |
| testB | 快速人台 | 4.53 / 9.38 / 4.59 | 12.42 / 21.50 / 12.60 | 4.69 / 9.56 / 4.68 |
| testB | 旧照片拟合 | 3.87 / 7.84 / 3.78 | 8.82 / 15.99 / 9.03 | 4.24 / 9.06 / 4.22 |
| testB | 新照片拟合 | 3.00 / 5.98 / 2.92 | 3.65 / 7.83 / 3.73 | 2.36 / 4.95 / 2.38 |

三种方法共同覆盖 testA 的 1,684 对（87 人）和 testB 的 1,160 对（400 人）。两种照片拟合在 testA 均为完整 1,042、部分可用 642、失败 0，在 testB 均为完整 599、部分可用 561、失败 0。部分可用表示输入有局部轮廓不确定性，这些样本仍计入误差。快速人台在两组分别成功 1,684 和 1,160 次。

两组所有部位的平均误差都有下降。个体差异较大，例如 testB 的 `6005af266732297800b0004a361e5328` 腰围误差从 0.78 cm 增至 20.45 cm。报告列出每组胸、腰、臀退步最大的拍摄 ID。以上精度适用于已分割的轮廓，实拍还受分割质量和衣服遮挡影响。[测试集完整结果](bodym.json) · [训练与验证记录](training.json)

## 浏览器与试衣

回归使用本地留存的同一组办公室正侧面实拍图。正面宽 565 像素，侧面宽 549 像素。两版均从创建页上传、生成、旋转、确认并导出。历史版本曾把手臂随腰部一起拉宽，修复前同一模板姿态两手间距为 165.27 cm，模块三基线已经降为约 108.3 cm。实拍中宽松上衣与上臂部分相连，故对有遮挡的躯干截面降低权重。原图没有真人软尺标签，本例能检验变形与人体比例，真人尺寸误差由带标签的测试集另行评估。

本次实拍导出人台的两手间距为 108.97 cm，同参数快速人台为 108.87 cm。历史的手臂过度拉伸在这组照片上没有复现。六件服装分别加载并检查了袖口、腰腹和下肢。浏览器另验收了一对同 ID 的原生 BodyM PNG，仅填写腰围 82 cm 时，预览复测为 82.0 cm。[实拍导出网格记录](photo-check.json)

## 本地复跑

从含 `package.json` 的目录运行。已有解析结果时可直接执行测试集评估。冻结参数随仓库提供。

```powershell
npm.cmd test
npm.cmd run bodym:evaluate
npm.cmd run geometry:verify
```

新工作区可先按项目 README 准备 BodyM，然后执行 `npm.cmd run bodym:parse`。如需复现选参与训练，执行 `npm.cmd run bodym:train` 后重新运行评估。

浏览器验收需要 Python Playwright、Chromium 和 Pillow。先运行 `node scripts/serve.mjs 4283`，然后在第二个终端执行下列命令。旧版脚本从本地 Git 对象读取 `3dbcdfa` 的源码。实拍输入默认使用模块二的 `.private/bodym-analysis/qa/front.png` 和 `side.png`，也可用 `--photos` 指定这两个文件所在的目录。已安装的 Chromium 可通过 `--browser` 指定。

```powershell
python scripts/verify-geometry.py --baseline
python scripts/verify-geometry.py
npm.cmd run geometry:verify
```
