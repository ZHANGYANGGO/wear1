源仓库历史中的二维创建通过文件指纹载入预制插画，身材数值用于记录。后来的面部编辑器挂载三维人台。此次迁入二维原版功能，并实现普通照片建档、人物选择和独立结果存储。二维美颜处理、彩妆绘制、照片卡通生成、身材参数驱动的二维图层形变属于后续算法模块。原版保存的是搭配记录，未发现面向用户的二维 PNG 导出控件。

## 复跑浏览器对照

在本项目安装了 Python Playwright、Pillow 并准备 Chromium 的情况下执行。原版服务需要相同的 12 张衣橱原图；`--portraits` 指向能递归找到原四张登记 PNG 的目录。`--browser` 也可省略，使用 Playwright 当前安装的浏览器。

```powershell
$baseline = '..\wear\wear\.private\baseline-2d'
$chrome = "$env:LOCALAPPDATA\ms-playwright\chromium-1134\chrome-win\chrome.exe"
# 在另一终端从基线目录运行 node scripts/serve.mjs 4376，再执行源端检查
python scripts/verify-migration.py baseline --source $baseline --portraits '..\人物' --url http://127.0.0.1:4376 --browser $chrome
# 关闭基线服务，启动本项目后执行目标检查
python scripts/verify-migration.py target --portraits '..\人物' --url http://127.0.0.1:4375 --browser $chrome
```

两轮按同一套动作分别生成 JSON。目标轮会与源端逐项比对人物、单品、图层、素材、像素摘要和天气推荐。源码见[浏览器验收脚本](../../scripts/verify-migration.py)。
