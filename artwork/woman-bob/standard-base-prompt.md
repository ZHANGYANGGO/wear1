# WearMate 短发女士标准换装底模

使用内置 ImageGen。参考图为当前项目的短发女士全身截图。

用附件仅作为当前 WearMate 短发女性的身份与画风参考，重绘一张 2D 虚拟换装标准基础母稿。保持同一成年东亚女性的窄鹅蛋脸、棕色眼睛、自然细眉、闭口浅笑、暖肤色、深棕齐耳侧分短发与发缝方向；面部年龄气质与参考一致。统一的 2D 轻写实时尚插画，柔和清晰描线，干净细腻。纯白 (#ffffff) 满幅背景，彻底移除参考图的拱门、边框、横线和舞台装饰，无地面线、无接触影、无投影、无字样。严格 1024×1536 纵向 2:3 构图，单人全身完整居中，头顶、双手、脚趾均留安全边距，成人约 7.2 头身。正交正面视图，正看镜头，双肩水平，腰胯平直，不转身，不侧头，不偏重一腿。轻 A-pose，双上臂向外自然下垂约 10–12 度、肘部柔和，双臂和手与躯干及大腿之间保留连续清晰白色空隙，五指自然略弯。双腿平行自然站直，左右对称，双裸足脚掌平踩、脚尖均朝正前方、脚底同一水平高度；不使用天桥步或外八。只穿浅米色圆领贴身有肩带无袖基础打底背心，露锁骨、双肩与腹部腰线（背心和短裤间小段自然留空），同色简洁贴身平角短裤（平整中短裤腿，素色、不透明）。裸露完整手臂、双腿、脚踝、整个脚背和脚趾。均匀柔和正面漫射光，无高反差、强方向性阴影或夸张透视。不要 3D、Q 版、照片质感、拼贴、夸张身材、过长腿、过小头、内衣蕾丝、长裤、裙、外套、任何鞋、额外文字或图框。用于后续透明拆层；输出纯白背景版本。
