# WearMate 穿搭助手

WearMate 是一个创意大赛穿搭原型。当前版本在浏览器中拟合可试衣的 3D 分身，支持旋转、导出 GLB 和试穿六件内置服装。用户也可单独调用 Tripo 生成外观参考。工程也保留了早期 2D 换装、数字衣橱和天气搭配的实现与验收记录。

## 本地运行

Windows 用户安装 Node.js 22 或更高版本后，双击 [启动WearMate.cmd](启动/启动WearMate.cmd) 即可打开 [3D 分身创建页](http://127.0.0.1:4294/create.html)。首次启动会补齐缺少的依赖，重复启动会打开已运行的服务。

以下命令从本 README 所在目录执行。使用 Node.js 22 或更高版本，以及支持 WebGL 的浏览器。

```powershell
npm.cmd ci
npm.cmd run dev
```

Windows PowerShell 下显式使用 `npm.cmd` 可避开 `npm.ps1` 的脚本执行限制。依赖已安装时，只需在仓库根目录运行 `npm.cmd run dev`。服务已运行时，直接打开 [3D 工作台](http://127.0.0.1:4173/)。

本机服务直接提供 HTML、JavaScript 模块和模型文件，无需构建前端。第一次打开时，工作台会提示创建分身。想先看换装效果，可以打开 [2D 角色演示](http://127.0.0.1:4173/stage1a.html)，用内置人物切换单品和整套搭配，无需云端凭据。

### 创建分身并试穿

打开[创建页](http://127.0.0.1:4173/create.html)，选择一档，生成后可以预览、下载 GLB，或确认并进入工作台。

| 建模方式 | 需要提供 | 用途 |
| --- | --- | --- |
| 快速人台 | 身高、体重 | 估计基础体型，可微调肩宽、腰腹、臀部。 |
| 双视角拟合 | 身高、体重、正面和侧面全身照 | 本地提取肩、胸、腰、臀的轮廓和上下身比例，拟合同一套人体模板。 |
| 实测围度 | 双视角输入，至少填写胸、腰、臀围中的一项（cm） | 用躯干网格闭环复测并校准已填写的部位。 |
| 外观增强 | 双视角输入，可选实测围度 | 先确认本地人台，再从工作台自选清晰正脸、侧面或背面照片并授权云端生成。可在工作台切换查看外观参考和试衣分身。 |

摄像头和文件上传使用同一套本地照片流程。通过本机地址打开网页，头脚完整入镜，固定机位并原地转身 90°。穿合身衣物、双臂稍离躯干更容易提取轮廓。支持 JPEG 或 PNG，每张最多 10 MB。照片质量不合适时可重拍，也可切换到快速人台。

在同一标签页进入[3D 衣橱](http://127.0.0.1:4173/wardrobe.html)试穿。身高对应模型实际高度，肩部及躯干参数同时作用于人物与服装。当前效果用于静态搭配预览，成衣松量、面料物理和真实尺码预测需要额外数据。

### 可选的云端外观参考

本地创建和试衣均可在无密钥时运行。需要外观参考时，在 `.env` 设置 `DASHSCOPE_API_KEY` 和 `DASHSCOPE_WORKSPACE_ID` 并重启服务。工作台的「选择照片并增强外观」会打开独立页面。用户在该页重新选择照片、勾选同意并点击上传后，Node 服务才向阿里云百炼 Tripo 提交计费任务。云端输出是独立 GLB，确认关联后用于外观对照。生成失败时可返回试衣分身。

模块三的网格复测、两种腹型投影对照、BodyM 新旧误差和复跑命令见[人体几何验收报告](reports/geometry/README.md)。

### 完善面部外观与妆容

确认本地人台后，在工作台选择“完善面部外观与妆容”。上传光线均匀、五官清晰的正脸近照，想改善鼻尖、嘴唇和下巴的侧面轮廓时，再补一张同人的侧脸。也可以直接在模板脸上试妆。使用“按住看原貌”可对照当前造型，确认后进入衣橱即可带妆换装。编辑页可分别下载原貌和造型 GLB。两部分的设计、实拍对照、离线导出检查和复跑命令见[面部造型设计与验收](reports/face/README.md)。

## 正侧面轮廓与 BodyM 离线解析

创建页照片通过检测后，可展开「查看正面轮廓」或「查看侧面轮廓」。每个视角复用同一次 MediaPipe 检测得到的关键点、可见性和分割遮罩。使用 BodyM 时选同一个拍摄 ID 的两张 PNG，正面来自 `mask/`，侧面来自 `mask_left/`。页面直接读取白色前景、黑色背景的二值遮罩。全身原图、轮廓和姿态关键点在创建页内存中处理。正面实拍满足条件时，确认分身会在当前标签页暂存一张脸部裁图，供面部编辑页读取一次。BodyM 二值图用于体型拟合，面部个性化需要另选真人照片。

在本目录运行以下命令。匿名同步脚本使用 Python、requests 和 Pillow，按官方 S3 清单比较对象键、长度和单段对象的 MD5，并对 PNG 做解码检查。重复运行会补齐缺损对象。[BodyM 官方数据说明](https://registry.opendata.aws/bodym/)

```powershell
python -m pip install requests Pillow
python -B scripts/sync_bodym.py
npm.cmd run bodym:parse
npm.cmd test
```

原始数据位于 `.private/datasets/bodym/`。打开 `.private/bodym-analysis/latest.json`，其中的 `dir` 指向本次完整运行。各分区的 `.ndjson.gz` 每行是一对正侧面解析记录，保留拍摄 ID、人物 ID 和身高体重等元数据。14 项量体标签按人物单存于 `*-measurements.json`。可用浏览器直接打开 `*-sample.svg`、`*-partial.svg`，与同名 JSON 对照。常规测试使用小型构造样例，可在没有 BodyM 的工作区运行。

每行轮廓保存相对高度、图像左边界和右边界。存在分开的前景段时，第四列保留每段的左右边界。脚底为 0，头顶为 1，横向偏移以原图中的人物像素高度为单位；缺失边界用 `null`。每张图的 `frame` 记录包围框中轴、顶底行和原图、检测输入、遮罩三种尺寸，可用 `originalPoint` 还原到原图像素中心。`issues` 使用遮罩的起止行标记局部不确定性，手臂与躯干未分离的外缘仍可见，不能直接用作腰线。BodyM 的相机和关键点均为未知。侧面朝向可判定时，`direction` 标明图像哪一边朝腹部。原生遮罩没有可靠朝向依据时保留 `null`。

统计以映射表记录为分母。`validPairs` 是两图均可读取和解码的对数；两图均提取完整可见边界为成功，任一视角出现局部不确定行段为部分可用，缺图、坏图或无法提取主体为失败。没有相机信息、关键点或朝向本身不会触发降级。

## 实现方式

| 环节 | 代码入口 | 处理方式 |
| --- | --- | --- |
| 采集与轮廓 | [创建页](src/create/create.mjs) · [照片分析](src/create/silhouette.mjs) | MediaPipe Pose Landmarker Lite 在浏览器中提取关键点和分割遮罩，比较正面宽度与侧面厚度。模型与 WASM 均由本机提供。 |
| 体型拟合 | [照片拟合](src/3d/photo-geometry.mjs) · [网格软尺](src/3d/mesh-tape.mjs) | 正侧轮廓共享体型，腹背方向可靠时可独立调整小腹位置。服装沿用同一变形和肩臂权重。创建页可显示最终网格的胸、腰、臀量线，GLB 保留米制尺寸。 |
| 试衣与导出 | [Three.js 查看器](src/3d/viewer.mjs) · [衣橱](src/wardrobe/tryon3d.mjs) | 在同一站姿下变形模板与服装顶点，用相机取景显示人物。下载的是已变形的试衣人台 GLB。 |
| 存储与外观 | [会话](src/3d/profile.mjs) · [云端处理](scripts/reconstruction.mjs) | 本地照片在页面内存中处理，确认的人台参数和参考 ID 保存在当前标签页的会话中。云端产物存入 `.private/3d-models/<任务ID>/`。 |

本地人体模板取自 CharacterCreator 的 MakeHuman CC0 人体，与现有六件服装共用站姿。本项目从源模型提取静态网格并设置人台材质。姿态模型使用 Google 发布的 Pose Landmarker Lite（float16，第 1 版）。[人体素材及许可](https://github.com/kblood/CharacterCreator/blob/master/LICENSE-NOTES.md) · [MediaPipe 文档](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js)

## 验证

在仓库根目录运行 `npm.cmd test`。测试覆盖本地体型拟合、模型实际身高、照片轮廓、围度约束、外观参考关联、3D 重建请求、GLB 服装资源、2D 图层、衣橱状态和天气规则。重建测试使用模拟云端响应，可在本地重复运行。
